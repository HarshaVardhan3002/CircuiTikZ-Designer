What can I paste here?

Two formats are supported. The importer figures out which one you have automatically — you don't need to pick.

  • JSON save file — anything the Save button produced, including legacy files from older versions of this app.
  • CircuiTikZ code — a \begin{tikzpicture}…\end{tikzpicture} block, or just a handful of \draw / \node lines on their own.
CircuiTikZ examples that work

Copy any of these snippets and paste them into the Paste code tab.

A simple voltage divider
\begin{tikzpicture}
  \draw (0,0) to[V=$V_\text{in}$] (0,3)
              to[R=$R_1$]         (2,3)
              to[R=$R_2$]         (2,0) -- (0,0);
\end{tikzpicture}
Named points you can reuse
\coordinate (A) at (0,0);
\coordinate (B) at (3,0);
\draw (A) to[R=1k] (B);
Transistors and other node symbols
\node [nmos] (M1) at (0,0) {};
\node [pnp]  (Q1) at (3,0) {};
Plain wires with bends
\draw (0,0) -- (2,0) -| (4,2) |- (6,4);
What happens if something goes wrong

If a line can't be understood, the importer will skip just that line and keep going. When it's finished, an Import report opens showing a summary and a list of every warning, including the exact line number and a plain-English explanation. Clicking a warning highlights the offending line in your source so you can find it instantly.

Known limits

Custom LaTeX macros (\newcommand, \def), \if/\else conditionals, and TikZ features beyond CircuiTikZ (plot, arc, Bezier curves) aren't expanded — they'll appear as warnings. Anchors like (R1.north) import as the named point itself; use numeric coordinates if you need precise placement.

Tip: if your file starts with \documentclass, just paste the contents of the \begin{tikzpicture}…\end{tikzpicture} block.

    About CircuiTikZ-Designer v1.1.0

    CircuiTikZ-Designer is part of the Circuit2TikZ-Project which was started as a research project at the Institute of Electronics Engineering at the Friedrich-Alexander-Universität Erlangen-Nürnberg. The goal was to create a GUI application for easy and fast drawing of circuits to be used in CircuiTikZ.

    If you find bugs or have suggestions, please feel free to contact us, preferably on Github.

    Help

    General

    • Saving your circuit regularly as a json file is recommended. This project is still in alpha!
    • Every new browser tab is a new canvas ready for drawing. You can manage the browser tabs in the settings menu.
    • Closing/Reloading the tab will not erase the drawn circuit. Reopening the tab will reload the circuit.
    • Closing/Reloading the tab will erase the editing history (Undo and redo will be lost).
    • Reloading the tab can sometimes be useful if you encounter bugs.
